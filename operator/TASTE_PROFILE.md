# Perfil de gosto do operador

Este perfil registra preferências recorrentes de direção, não fatos do cliente nem uma identidade visual pronta. Ele orienta a calibração visual e nunca substitui briefing, marca, referências autorizadas ou uma instrução explícita do cliente.

## Como preencher

- Atualize antes da Fase 2B ou quando uma revisão revelar preferência recorrente.
- Registre referências pelo princípio, nunca como layout a copiar.
- Use `pendente` quando não houver decisão; não deixe a IA inferir uma preferência a partir de um único projeto.
- Uma preferência desta página não é regra absoluta: cada cliente ainda precisa de direção própria aprovada.

## Protocolo quando houver lacuna

Se este perfil ainda estiver pendente antes de uma decisão visual relevante, peça ao operador, de forma curta:

1. três sites de que ele gosta e o que chama atenção em cada um;
2. dois sites ou padrões que ele não quer repetir;
3. a ordem de prioridade entre originalidade, conversão, mobile, velocidade e manutenção.

Registre a resposta aqui e use-a para comparar as duas direções da Fase 2B. Não use o perfil para publicar fatos, escolher assets sem autorização ou substituir a aprovação humana.
