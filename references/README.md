# Referências de desenvolvimento

Estas fichas ajudam a IA a entender o nível de acabamento e o tipo de decisão que a VelozeWeb busca. Elas não são bibliotecas de templates.

## Regra de uso

Pode reutilizar o princípio (por exemplo, uma narrativa progressiva ou uma interação de escrita) quando fizer sentido para o novo cliente. Não pode copiar logo, identidade, textos, imagens, código, composição integral ou a aparência reconhecível de uma referência.
